核对日期 2026-09-26。MaaAI #14 固定 `c6ba2eb6`，MAA #18246 固定 `59392bd2`，两者仍未合并；本分支直接从 MaaAI main `7250cacc` 开始，只吸收我能单独说明并验证的改动。运行基线为 MAA v6.18.0。
