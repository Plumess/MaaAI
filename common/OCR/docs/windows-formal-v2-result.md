## 官方发布版 GUI 补测（2026-09-27）

随后在同一台 Windows/MuMu 国服环境中，用官方 v6.18.0 ZIP 解压两份完整 GUI，候选侧只覆盖 12 个识别资源。10,107 个发布文件比较恰好只有这 12 项不同；两侧 `MaaCore.dll`、`MaaUtils.dll` 与官方 ZIP 一致，运行后复核未变。原始交接包 `windows-gui-release-core-v2.zip` 的 SHA-256 为 `df27d42d902ac1efc083a448dc329f6041638e145edcb948fd9ff3a506915895`；本地已核验包内 20 项文件哈希、资源差异、GUI/核心日志与业务输出。

两版 GUI 均成功启动、连接同一模拟器并截图，且均使用未修改的发布核心完成公招和仓库识别。公招五个可见标签与画面一致；仓库四项画面可精确读出的数量均正确，71 个输出字段两版一致。该测试是顺序进行的发布版黑盒对照，ADB 观察截图不是 MAA 内部实际输入的原始字节；其余库存字段只证明两版输出一致，不宣称逐项独立真值正确。此轮没有在发布版 GUI 中实测 `0-1` 和战斗费用 `0`；它们的同源码探针证据仍按前述范围解释。

因此此前“GUI 未测”的限制已缩小为：**发布版 GUI 的已测国服公招与仓库路径通过，其他任务场景未由这份补测覆盖**。未修改发布版 DLL 不提供离线图片直调内部 OCR 的公开接口；不能把该独立项目写成已测通过，也不应把“接口不可用”误写成模型失败。外服实图与候选性能仍按原边界记录。
